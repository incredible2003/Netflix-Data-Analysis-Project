# Netflix-Data-Analysis-Project
Analyzed Netflix dataset using Python, Pandas, Matplotlib, and Seaborn. Performed data cleaning, exploratory data analysis (EDA), and created visualizations to identify trends in content type, ratings, release years, and genres.
## Netflix Data Analysis Project
Analyzed Netflix dataset using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

### Key Tasks
- Data Cleaning
- EDA (Exploratory Data Analysis)
- Visualization using charts and graphs
- Trend analysis by year and content type

### Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
